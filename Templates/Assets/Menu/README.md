# Menu

## Tabbed menu base (2.8.0)
`Prefabs/Tabbed Menu – Canvas` is a ready menu shell: a canvas with `UIShowHide`, console and gamepad navigation (`ConsoleMenuNavigation`, `GamepadUIEnabler`, `CursorVisibleMenuChanger`), a backdrop, the LB / RB tab prompts, a tab strip (`TabsController`) and two placeholder tabs. Replace the placeholder panels with your own panels (for example `Inventory – Panel` and `Craft – Panel` from the inventory package) and point the `TabsController` entries at them. The navigation actions are found by the paths `UI/Cancel`, `UI/PreviousPage` and `UI/NextPage` in your Input Actions, or assign them on `ConsoleMenuNavigation`.

`Prefabs/Slider with Value` is a slider with a value label. `Animations/` has the button and dropdown animators.

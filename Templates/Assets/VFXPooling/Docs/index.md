# VFX Pool

Эффекты (`ParticleSystem`) не живут внутри каждого врага, а берутся из общего пула: заранее созданные экземпляры
выдаются на время удара и возвращаются обратно. На враге остаётся только пустышка (`VFXPoolElement`) - точка,
поворот и размер, где эффект должен появиться.

## Зачем

Раньше у каждого волка внутри было 114 `ParticleSystem` (5 эффектов, из них «Sword Slash» - по 8-9 систем) и 189 `Transform`.
Все они ехали вместе с волком каждый кадр, даже когда ничего не играло: каждая смена позиции родителя помечает
изменёнными всех детей, и Unity пересчитывает их матрицы. После перевода на пул:

| Префаб | `ParticleSystem` было -> стало | `Transform` стало |
|---|---|---|
| Wolf Realistic | 114 -> 4 | 84 (было 189) |
| Bear | 61 -> 4 | 81 |
| Bear_VAT | 59 -> 4 | 17 |
| Shadow Unicorn (и варианты, 116 штук на Snow World) | 13-14 -> 3 | 99-101 |

У зверей оставшиеся 4 системы - эффекты баффов (`FireBuff`, `PoisonBuff`), на них ссылается код напрямую. У единорогов остаётся `Attack` (в нём снаряд, на который указывает `UnicornAIUnit`).

Второй выигрыш - общие экземпляры: десяти волкам нужно столько эффектов, сколько ударов идёт одновременно, а не
десять наборов.

## Из чего состоит

| Что | Где | Роль |
|---|---|---|
| `VFXPool` | на `PLAYER.prefab`, `DontDestroyOnLoad` | хранит пулы по `id`, выдаёт и возвращает экземпляры |
| `VFXPrefabsContainer` | `Assets/ScriptableData/VFXPrefabsContainer.asset` | список эффектов: `id`, префаб, длительность, петля, прогрев |
| `VFXPoolElement` | пустышка на враге | `Play()` / `Stop()`: эффект появляется в её позе |
| `VFXPoolElementInvoker` | на корне врага | замена `ParticlesInvoker`: тот же список по индексу и имени |

`ParticlesActivator`, `VATParticlesActivator` и `ParticlesBlendTreeActivator` работают с обоими: если на объекте
нет `ParticlesInvoker`, они берут `VFXPoolElementInvoker`.
